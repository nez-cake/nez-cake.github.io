# 토스 입금 알림 샘플
#
# ============================================================
# 1. 가상 샘플 - 실제 토스 알림이 아닙니다.
#    "가상 샘플, 1원 테스트 후 교체". 파서 동작 확인용입니다.
# ============================================================
# 형식: 알림 하나는 TITLE: 줄과 BODY: 줄. 알림 사이는 빈 줄.
# '#'으로 시작하는 줄은 주석입니다.

# [가상] 이름 있는 입금
TITLE: 토스뱅크
BODY: 홍길동님이 38,000원을 입금했어요

# [가상] 타행 이체 (은행명 괄호)
TITLE: 입금 알림
BODY: 홍길동(국민) 38,000원 입금

# [가상] 제목에 금액, 본문에 이름
TITLE: 입금 38,000원
BODY: 홍길동 · 토스뱅크

# [가상] 이름 없이 금액만
TITLE: 토스뱅크
BODY: 38,000원 입금

# [가상] 무시해야 하는 알림: 출금
TITLE: 토스뱅크
BODY: 12,000원이 출금됐어요

# [가상] 무시해야 하는 알림: 결제
TITLE: 토스뱅크
BODY: 카페에서 4,500원 결제됐어요

# [가상] 무시해야 하는 알림: 이자
TITLE: 토스뱅크
BODY: 이자 123원이 들어왔어요

# [가상] 무시해야 하는 알림: 광고
TITLE: (광고) 토스뱅크
BODY: 이번 주 혜택을 확인하세요

# ============================================================
# 2. 실제 원문 붙여 넣는 곳 (1원 테스트 후)
# ============================================================
# 방법 (docs/SHORTCUT.md의 1원 테스트):
#  1) 단축어 자동화가 메모 앱에 남긴 알림 내용을 길게 눌러 복사
#  2) 아래 "실제 원문" 영역에 그대로 붙여 넣기. 이름, 금액, 줄바꿈, 띄어쓰기를 고치지 말 것.
#  3) 어느 경로인지 한 줄 주석으로 표시: 토스 송금 / 타행 이체 / 잠금 중 / 사업자 통장 등
#  4) 관리 세션에 알려 주세요. 파서의 NOTIFICATION_PATTERNS를 이 원문에 맞춰 교체합니다.
#  (개인정보: 계좌번호가 보이면 지워 주세요.)

# --- 실제 원문 시작 ---
# 1원 테스트로 확인한 토스뱅크 형식. 저장소가 공개라 이름은 가짜("홍길동")로 바꿔 적었습니다.
# 사용자가 손으로 옮겨 적은 것이라 화살표(->, →)와 공백은 다를 수 있어 파서가 모두 받습니다.
# 제목/본문 분리(title, body)는 단축어 설정에 따라 달라서, 파서는 둘을 합쳐 읽습니다.
# 아직 미확인: 잠금 중 실행, 타행 이체 경로, 사업자 통장의 문구.

# [실제 형식] 2원 이상 입금 (이름 보임)
TITLE: 60,000원 입금
BODY: 홍길동 -> 내 토스뱅크 통장

# [실제 형식] 1원 입금 (이름이 ****로 가려짐 -> name 없음)
TITLE: 1원 입금
BODY: **** -> 내 토스뱅크 통장
