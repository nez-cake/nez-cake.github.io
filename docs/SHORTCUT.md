# 아이폰 단축어 설정 (입금 알림 → Apps Script)

토스 입금 알림이 뜨면 단축어 자동화가 알림 내용을 서버로 보내게 하는 설정이다. 코드로 만들 수 없어 손으로 한다.

**먼저 알아둘 것**

- iOS 27 이상이 필요하다. 설정 → 일반 → 정보에서 버전을 확인한다.
- iOS 27에서 자동화는 단축어 앱의 **보관함(Library) → 자동화**에 있다. 메뉴와 버튼 이름은 이 문서와 다를 수 있으니 비슷한 항목을 찾는다.
- 아직 검증되지 않은 것: 알림 자동화가 **확인 없이** 도는지, **잠금 중에** 도는지, 토스 알림에 **입금자명과 금액이 함께** 있는지. 아래 1단계(1원 테스트)가 이걸 확인한다. 결과를 알려 주면 그에 맞게 파서와 흐름을 고친다.
- 비밀 토큰 값은 이 문서에 적지 않는다. 값은 백엔드 담당이 만든 Script Properties의 `DEPOSIT_TOKEN`을 쓰고, 단축어 안에만 붙여 넣는다. 화면 캡처나 채팅에 올리지 않는다.

## 1. 1원 테스트 (코드 필요 없음, 약 10분)

목적: 알림이 단축어까지 오는지, 어떤 문구인지 확인하고 실제 원문을 얻는다.

### 1-1. 테스트용 자동화 만들기

1. 단축어 앱 → 보관함 → 자동화 → 새 자동화(+).
2. 트리거로 **알림(앱 알림)** 을 고른다.
3. 앱은 **토스**(토스뱅크 알림이 별도 앱으로 오면 그 앱도)를 선택한다. 앱 선택이 안 되면 알림 트리거 자체가 안 되는 것이니 그 화면을 기록해 알려 준다.
4. **필터(알림에 포함된 텍스트)는 비운다.** 처음에는 어떤 문구가 오는지 모르므로 토스 알림을 전부 받는다. (메모가 늘어나는 건 테스트 후 지우면 된다.)
5. 동작으로 **메모에 추가**(또는 "메모 만들기")를 넣고, 내용에 **단축어 입력(Shortcut Input)** 의 알림 내용을 넣는다. 제목과 본문이 따로 고를 수 있으면 둘 다 넣고, 사이에 줄바꿈을 둔다.
6. 실행 옵션에서 **실행 전에 확인 끔**, **잠겨 있는 동안 실행 허용 켬**을 찾아 설정한다. 이 스위치가 없거나 켜지지 않으면 그 사실을 기록한다. (애플 설명서의 "확인 없이 실행 가능한 자동화" 목록에 알림 트리거가 없어서 안 될 수도 있다.)
7. 완료.

### 1-2. 시험 (경로별로 각각)

다른 은행 앱이나 다른 사람 계좌에서 내 토스뱅크 통장으로 **1원**을 보낸다. 아래 경우를 모두 해 본다.

| # | 경로 | 화면 상태 |
| --- | --- | --- |
| 1 | 토스 앱 송금 (보내는 사람이 토스 사용자) | 폰을 켜 둔 상태 |
| 2 | 타행 이체 (다른 은행 앱에서 계좌번호로) | 폰을 켜 둔 상태 |
| 3 | 토스 앱 송금 | **화면 잠금** 상태 |
| 4 | 타행 이체 | **화면 잠금** 상태 |

보내는 사람 이름은 **실제 입금자명 그대로** 알아 두고, 가능하면 이름에 공백이나 괄호가 있는 경우도 한 번 시도한다.

매번 확인할 것:

- 알림이 오자마자 메모에 내용이 추가되는가? 아니면 "실행할까요?" 같은 확인이 뜨는가?
- 잠금 상태에서도 메모에 추가되는가? (잠금 해제 후 메모를 열어 확인)
- 메모에 **입금자명과 금액이 둘 다** 찍히는가?
- 알림이 오지 않거나 중복으로 오는가?

### 1-3. 원문 전달

메모에 찍힌 내용을 **그대로** 복사해서 `samples/notifications.txt` 아래쪽 "실제 원문" 영역에 붙여 넣는다(방법은 그 파일 안에 적혀 있다). 경로(1~4번)를 한 줄 주석으로 달고, 시험 결과(확인 없이 실행/잠금 중 실행/입금자명 포함 여부)를 같이 알려 준다. 계좌번호가 보이면 지운다.

## 2. 웹훅 연결 (백엔드 웹 앱 배포 후)

1-1의 자동화를 고쳐서 서버로 보낸다. 웹 앱 배포 주소와 토큰은 백엔드 담당이 알려 준다(`docs/SETUP.md`).

1. 자동화를 열어 메모 동작을 지우고 **URL 콘텐츠 가져오기**를 넣는다.
2. URL에 웹 앱 배포 주소를 붙여 넣는다.
3. "표시 ▸" 에서 방법을 **POST**, 요청 본문을 **JSON**으로 바꾼다.
4. 필드를 추가한다.

   | 키 | 값 |
   | --- | --- |
   | `action` | `deposit` (텍스트) |
   | `token` | 비밀 토큰 (텍스트, 직접 붙여 넣기) |
   | `title` | 단축어 입력의 알림 **제목** |
   | `body` | 단축어 입력의 알림 **본문(메시지)** |
   | `receivedAt` | **현재 날짜**. 형식은 ISO 8601이 가장 좋다. (날짜 형식 지정 가능하면 ISO 8601로. 안 맞아도 서버가 수신 시각을 대신 쓴다.) |

5. 필터를 "입금"으로 좁히는 것은 **실제 원문을 확인한 뒤**에 한다. 출금·결제 알림이 와도 서버가 "무시"로 기록하므로 처음에는 비워도 된다.
6. 실행 전 확인 끔, 잠금 중 실행 켬(1-1의 6번과 같음).
7. 1원을 다시 보내서 시트의 Deposits 탭에 행이 생기는지 본다. 응답이 `ok: true`가 아니면(결과 보기 단계에 응답을 보이게 해 두면 확인된다) 백엔드 담당에게 알린다.

## 3. 사장님 폰으로 옮기기

1. 사장님 아이폰이 iOS 27 이상인지 확인한다. 아니면 업데이트한다.
2. 사장님 폰에서 2번을 처음부터 다시 만든다. (단축어 공유로 복사하면 토큰이 공유 링크에 담길 수 있으니, 가능하면 직접 만들고 토큰은 붙여 넣기로 넣는다.)
3. 토스뱅크(사업자 통장) 알림이 어떤 앱 이름으로 오는지 보고 1-1의 3번처럼 앱을 고른다.
4. 사업자 통장으로 1원 테스트(1-2의 경로 1~4)를 다시 하고 원문을 `samples/notifications.txt`에 추가한다. 문구가 개인 통장과 다르면 파서에 형식을 추가해야 한다.
5. 영업 중 폰 상태를 확인한다: 잠금, 집중 모드, 저전력 모드, 토스 앱 알림 허용이 켜져 있어야 한다. 집중 모드에서는 알림이 안 올 수 있으니 토스를 집중 모드의 허용 앱에 넣는다. 안 되면 영업 중에는 폰을 충전기에 두고 화면을 켜 둔다.
6. 토스 앱 알림을 끄거나 앱을 지우면 자동화가 멈춘다. 오픈 기간에는 건드리지 않는다.

## 4. (선택) 살아 있음 신호

매시간 서버에 "나 살아 있음"을 보내는 **시간 자동화**를 만들면, 알림 자동화가 멈췄을 때(재부팅 후 등) 서버가 알아챌 수 있다.

- **선택 사항이며, 지금은 쓸 수 없다.** 서버에 이를 받는 API(예: `action=heartbeat`)를 추가해야 하고, 그건 관리 세션이 API 계약에 넣기로 정해야 한다.
- 지금의 안전망은 매일 아침 입금대기·미매칭 목록 메일과 "입금 수신이 하루 넘게 없으면 경고 메일"이다(SPEC.md 8장).

## 문제가 생기면

| 증상 | 확인 |
| --- | --- |
| 자동화가 아예 안 돔 | 토스 알림 허용 여부, 자동화 켜짐 상태, 폰 재시작 후 한 번 확인 |
| 돌 때마다 확인창이 뜸 | 실행 전 확인 스위치. 끌 수 없으면 알림 방식 불가 → 대안(SPEC.md 8장) 검토 |
| 잠금 중에는 안 돔 | 잠금 중 실행 허용 스위치. 안 되면 영업 중 화면을 켜 둠 |
| 서버가 UNAUTHORIZED | 토큰 오타. 앞뒤 공백이나 줄바꿈이 붙지 않았는지 |
| 시트에 "미매칭"으로만 쌓임 | 알림 원문이 파서 형식과 다름 → 원문을 samples에 붙여 알려 줌 |
