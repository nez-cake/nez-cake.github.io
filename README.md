# 크리스마스 홀케이크 예약 시스템

인스타그램 링크 하나로 크리스마스 홀케이크 예약을 받는 시스템이다.

| 폴더 | 내용 |
| --- | --- |
| `web/` | 정적 주문 페이지 (GitHub Pages 등에 배포) |
| `apps-script/` | Google Apps Script 웹 앱 (clasp 프로젝트) |
| `tests/` | 입금 매칭 로직 Node 단위 테스트 |
| `samples/` | 토스 입금 알림 원문 샘플 |
| `docs/` | API 계약서, 설치 안내(SETUP.md), 단축어 설정(SHORTCUT.md) |

설계는 [SPEC.md](SPEC.md), 프론트와 백엔드 사이 약속은 [docs/API.md](docs/API.md)를 본다.
